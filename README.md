# Yomikai PWA

Веб-двойник Android-читалки [yomikai](https://github.com/sj0404-collab/yomikai) на **React + TypeScript (TSX) + Vite**,
оформленный как PWA: устанавливается на домашний экран, работает оффлайн (оболочка, библиотека, настройки).

## Что зеркалит Android-версию
- Нижние вкладки: Библиотека, Локальное, Обновления, История, Каталоги, Браузер, AI-чат, Ещё.
- Читалка: порядок чтения RTL/LTR/вертикаль, плавающее SAO-меню (порядок, автопрокрутка,
  «прочитать страницу», OCR скан), озвучка Web Speech API с пресетами пол×возраст
  (те же множители pitch/rate: муж 0.8 / жен 1.16 / средний 1.0; младенец 1.85 → пожилой 0.82),
  подсветка читаемого, карточка результата OCR с «Голос/Копировать/Закрыть».
- OCR: tesseract.js (rus+eng) по демо-страницам и по файлам картинок в браузере.
- Браузер: URL-бар + iframe (с честной подсказкой про X-Frame-Options) + OCR из картинки.
- AI-чат: любой OpenAI-совместимый эндпоинт (url/ключ/модель хранятся локально).
- **Конструктор** (Ещё → Конструктор): скрытие и перестановка вкладок, скрытие модулей панелей
  читалки/браузера, создание/редактирование/удаление своих кнопок с замкнутым списком эффектов
  (тема, пресет голоса, порядок чтения, стоп озвучки) — как в Android-версии.
- Всё состояние — в localStorage, переживает перезапуск; service worker держит оболочку оффлайн.

## Чем не является «точной копией» (осознанно)
Веб не даёт нативных OCR-моделей sherpa/CTC, системных TTS-движков RHVoice/Google, расширений
источников (APK-плагинов) и подписанного APK. Поэтому: OCR = tesseract.js, озвучка = Web Speech,
источники = демо-заглушки, дистрибуция = установка PWA вместо APK.

## Разработка и сборка
```bash
npm install
npm run dev      # локально
npm run build    # typecheck + vite build -> dist/
```

# Yomikai PWA

Веб-двойник Android-читалки [yomikai](https://github.com/sj0404-collab/yomikai) на **React + TypeScript (TSX) + Vite**,
оформленный как PWA: устанавливается на домашний экран, оболочка работает оффлайн.

Живой сайт: **https://sj0404-collab.github.io/yomikai-pwa/**

> Полная копия Android-репозитория (код, история, все 99 тегов) лежит в ветке `main` этого
> репозитория — её не трогаем. PWA живёт в ветке **`pwa`** и деплоится на Pages автоматически.
> Старый скейлет — ветка `pwa-scaffold-v1`.

## Вкладки (нижняя панель, как в APK)
- **Библиотека** — сетка тайтлов, прогресс, добавление своего тайтла.
- **Каталоги** — демо-источники (в вебе нет APK-расширений): «Открыть сайт» → Браузер, «Демо-тайтл» → в библиотеку.
- **История** — последние открытия, переход к тайтлу.
- **Читалка** — режимы RTL/LTR/вертикаль, автопрокрутка, SAO-меню, «Прочитать страницу»,
  скан зоны пальцем (выделил прямоугольник → OCR), карточка результата сверху сбоку
  с «Голос/Копир./Закрыть» и подсветкой текущей фразы.
- **Браузер** — адресная строка (адрес или поиск), назад/вперёд, ⟳ = перезагрузка того же сайта,
  закладки по умолчанию (RU: Манга · Mangabuff/Remanga/MangaLib/ReadManga/MintManga,
  Аниме · AnimeVost/AniLibria/AnimeBest, Ранобэ · RanobeLib/NoveLib), открытие внешней вкладкой ↗
  (многие сайты запрещают iframe — X-Frame-Options).
- **AI-чат** — любой OpenAI-совместимый эндпоинт (url/ключ/модель хранятся локально).
- **Ещё** — тема, озвучка (скорость/тон/голос), **Конструктор** вкладок: порядок, видимость,
  свои кнопки с эффектами (тема, пресеты голоса Ж/М/нарратор, режим читалки, стоп озвучки), сброс данных.

## Озвучка
Web Speech API с пресетами пол×возраст (те же множители, что в APK):
питч муж 0.8 / жен 1.16 / нарратор 1.0; возраст младенец 1.85 → пожилой 0.82.
Текст режется на предложения, вопросы/восклицания получают интонацию, текущая фраза подсвечивается.

## OCR
tesseract.js (rus+eng) подгружается с CDN **только при первом скане** — бандл не тяжелеет,
языковые данные кэшируются браузером. Сканируется либо выбранная пальцем зона страницы,
либо текст демо-страниц (встроен в SVG).

## Чем не является «точной копией» (осознанно)
Веб не даёт нативных OCR-моделей sherpa/CTC, системных TTS-движков RHVoice/Google,
APK-расширений источников и подписанного APK. Поэтому: OCR = tesseract.js, озвучка = Web Speech,
источники = демо-заглушки, дистрибуция = установка PWA вместо APK.

## Разработка и сборка
```bash
npm install
npm run dev      # локально
npm run build    # typecheck + vite build -> dist/
```
